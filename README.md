## 🌿 Overview

This repository contains a full-stack, responsive academic portfolio web application built for the **E-Waste Management** course. It provides faculty members with a central dashboard to browse, search, inspect, preview, and download all **22 real course assignments, handwritten notes, high-resolution infographics, SPCB diagnostic reports, state data models, and research papers**.

### Key Portfolio Sections:
1. **Overview Dashboard:** Live computed statistics from 22 verified files, student credentials badge, and featured submissions showcase.
2. **Assignment Library:** Interactive repository featuring live search, multi-category filters, file-type filters, sort options, grid/table views, full-detail modals, and direct downloads.
3. **Posters & Infographics Gallery:** High-resolution visual gallery with interactive zoom and technical commentary for all posters, comics, and flowcharts.
4. **Research & Data Analysis:** Interactive Recharts visual charts based on empirical datasets:
   - **Sikkim Sub-National Field Assessment (FY 2026):** 310.5 tonnes generation, 18.2 tonnes formal collection (5.86% capture rate), district divide, and 100-point state audit scorecard (46.1/100).
   - **SPCB Soil & Sediment Pollution Diagnostics:** Dumpsite concentrations vs. baseline for PBDEs (8,100 ng/g), PCBs (950 ng/g), SCCPs (30,200 ng/g), Copper (1,620 µg/g), and Lead (1,180 µg/g).
   - **Recoverable Strategic Metals:** Breakdown of Gangtok, Namchi, Mangan, Gyalshing, Pakyong, and Soreng.
   - **India vs. Global Benchmarks:** Growth from 1.97 MT (2015) to 3.23 MT (2019) vs. China, USA, Japan, Germany, and UK.
5. **Notes & Scanned Documents Viewer:** Dedicated in-browser reader with zoom controls preserving original handwritten notes (Toxic Heavy Metals: Pb, Cr, As, Cd, Hg with WHO limits) and multi-page assignment PDFs.
6. **Interactive Tools:** Embedded Central Pollution Control Board (CPCB) E-Waste EPR Registration & Target Calculator (`ewaste_epr_app-blue.html`).
7. **Academic Profile:** Student identity card, curriculum credit breakdown (HSSM bucket, ISA 75 marks), and complete 22-asset verification registry.

## 🛠️ Technology Stack

- **Frontend Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS (Custom environmental palette: Forest green, emerald, charcoal, subtle lime accents)
- **Data Visualizations:** Recharts (Bar charts, pie charts, tooltips, responsive grids)
- **Iconography:** Lucide React
- **Document Previews:** In-browser modal with zoom in/out, slide-selector, external tab preview, and authentic download links.
- **Theme Support:** Dark Mode & Light Mode with `localStorage` persistence.

## 🔄 Adding Future Assignments

To add future coursework or assignments to this static portfolio:
1. **Place the File:** Add the new assignment PDF, image, document, or spreadsheet to the appropriate folder under `public/`:
   - `public/assignments/` (general assignments)
   - `public/posters/` (visual posters & comics)
   - `public/diagrams/` (process flowcharts)
   - `public/reports/` (research manuscripts & decks)
   - `public/notes/` (handwritten notes)
   - `public/datasets/` (Excel trackers)
2. **Register in Catalogue:** Open `src/data/catalogue.ts` and append a new entry to `ASSIGNMENT_CATALOGUE` with:
   - Unique ID, title, category, description, public asset path, file type, file size, tags, and key highlights.
3. **Verify Previews & Downloads:** Run `npm run dev` to confirm the item appears in the library, previews open properly, and the download button works.
4. **Rebuild & Redeploy:** Run `npm run build` and push the updated bundle to your GitHub repository connected to Vercel.

*(Note: Because this is a high-performance static website, new bundled files require a quick build and deployment rather than in-browser file uploads).*

## ☁️ Deployment Guide (Vercel)

This application is 100% compatible with **Vercel** for public faculty evaluation:

### Option A: Using the Vercel Web Dashboard (Recommended)
1. Push your repository to GitHub.
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select this repository: `EWEM_Dashboard`.
4. Framework Preset: **Vite** (auto-detected).
5. Build Command: `npm run build` (auto-detected).
6. Output Directory: `dist` (auto-detected).
7. Click **"Deploy"**. Your live URL will be generated within ~30 seconds (e.g., `https://tanmay-ewaste-portfolio.vercel.app`).

### Option B: Using Vercel CLI
```bash
npm install -g vercel
vercel
vercel --prod
```
